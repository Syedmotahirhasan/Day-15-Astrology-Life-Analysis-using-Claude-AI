Day 15 – Astrology & Life Analysis using Claude AI

This repository documents the Day 15 project, where Claude AI is used to generate a personalized Astrology & Life Analysis report. It includes the prompt used, generated analysis, screenshots of key report sections, and project documentation. The repository demonstrates effective prompt engineering, AI-assisted content generation, report organization, and version control using Git and GitHub.

Features
AI-generated Astrology & Life Analysis report
Career and Wealth Analysis
Relationship and Life Pattern Analysis
Forecasts and Personalized Recommendations
Screenshots of important report sections
Project documentation and key learnings
Git version control with commit history
